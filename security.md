# Security Statement

# Intended users
The intended users of this repo are myself, Nathan Arnold, and Matt Lamoureux, who is the professor for this course. This is so he and I can look at the repo as well as him being able to grade my work.

# Assesment of the risks
* **Data Concerns:** The repository contains homework, projects, and work that is given by the university, which should be secured by FERPA and not distributed without my consent and/or the instructor's.
* **Security Threats:** If accessed by anyone else, potential risks include academic integrity violations or leaks of my private information if it is put somewhere in here. My code, if this were a cybersecurity course, could also be used to attack people using the code present in the repo instead of in a controlled environment.

# Security Steps Taken
* The link was provided to me and the class to the fork of the repo. I then created a clone of it on my github/vscode. This way, only Matt and I can see the changes when I push them to him. I cannot push any students' work to Matt, and neither can the other students for mine.
* We use pull requests so only I and I alone can change code on my end. Then it makes sure I didnt break the code when I try to pull request to Matts end.
* We have a  `.gitignore` file is which can stop sensitive data, passwords, or local files from being committed, only the ones in the repo
